PENGENALAN BIG DATA ANALYTICS

Asas data, klasifikasi, ciri data berkualiti, konsep 5V Data Raya serta evolusi teknologi data.

01
1.1

Pengenalan Kepada Data

Definisi Data
"Data ialah maklumat mentah yang dikumpulkan melalui pemerhatian, interaksi, atau sistem — dan digunakan untuk mengenal pasti corak, membuat keputusan, serta meramal tingkah laku."
3 Prinsip Utama
1

Setiap interaksi, transaksi atau perkhidmatan menghasilkan data

2

Data membolehkan kita memahami realiti, bukan sekadar bergantung pada andaian

3

Digunakan untuk penambahbaikan proses, pengukuran prestasi, dan perancangan masa depan

1.2

Klasifikasi Data

Klik tab untuk melihat setiap kategori
01

Data Berstruktur

Data yang tersusun dalam format tertentu seperti jadual dalam pangkalan data.

Contoh: Variabel yang disimpan di dalam Pangkalan Data seperti Nama, umur, alamat.
02

Data Tidak Berstruktur

Data yang tidak mengikut format tetap dan sukar dikategorikan.

Contoh: Gambar, video, audio, dokumen PDF.
03

Data Separa Berstruktur

Data yang mempunyai struktur tertentu tetapi tidak sepenuhnya seperti pangkalan data tradisional.

Contoh: JSON, XML, CSV.

Data Kuantitatif (Numerik)

Nombor

Data berbentuk nombor yang boleh dikira atau diukur.

Contoh: Jumlah pelajar dalam kelas: 35 orang; Suhu harian: 28°C.
1. Data Diskrit

Nilai tetap dalam nombor bulat dan tidak boleh dipecahkan.

Cth: Bilangan ahli keluarga: 1, 2, 3...; Bilangan telur dalam karton.

2. Data Berterusan

Nilai yang boleh diukur dalam satu julat dan boleh ada perpuluhan.

Cth: Berat badan: 55.5 kg, 60.2 kg; Suhu air.

Data Kualitatif (Kategori)

Bukan Nombor

Data bukan nombor yang menerangkan ciri atau kategori sesuatu perkara. Tidak boleh dikira secara matematik tetapi boleh dikelaskan dan dibandingkan.

Contoh Kategori:
  • Warna kereta: merah, biru, hitam
  • Tahap kepuasan: rendah, sederhana, tinggi
  • Pekerjaan: doktor, guru, jurutera

Data Primer (Primary Data)

Sumber Asal
Sumber Pengumpulan

Dikumpul sendiri oleh penyelidik melalui survei, eksperimen, temu bual, atau pemerhatian.

Kelebihan

Lebih relevan, terkini, dan menepati keperluan kajian.

Kekurangan

Kos tinggi, mengambil masa lama, dan risiko bias jika tidak dikawal.

Data Sekunder (Secondary Data)

Sumber Sedia Ada
Sumber Pengumpulan

Diperoleh daripada sumber sedia ada seperti agensi kerajaan, jurnal akademik, atau laporan organisasi.

Kelebihan

Mudah dan cepat didapati, serta menjimatkan kos dan tenaga.

Kekurangan

Mungkin kurang tepat, sudah lapuk, dan tidak mengikut keperluan khusus kajian.

Data Types in C

Primitive int, float, double, char
Derived Array, Function, Pointer
User Defined Structure, Union, Enum

Jenis Data Umum

Integer Float / Double Character String Boolean Date / Time Arrays 2D Arrays
NOTA PENTING Jenis data sangat penting dalam pemprosesan dan penganalisisan data besar.

Ciri-Ciri Data Yang Berkualiti

Relevan

Lengkap

Tepat

1.4

Konsep Data Raya (Big Data) & 5V

Definisi Data Raya (Big Data)

"Big Data merujuk kepada data berskala besar, pelbagai jenis, dan berubah dengan cepat, yang memerlukan kaedah baharu dari segi penyimpanan, pengurusan dan penganalisisan bagi tujuan membuat keputusan dengan lebih tepat dan pantas."

01 / 5V

Volume (Jumlah)

Jumlah data yang sangat besar (dari MB/GB ke Terabyte, Petabyte, Exabyte).

Konteks Perpustakaan: Jutaan rekod pinjaman, log carian OPAC, dan capaian e-jurnal setiap tahun.
02 / 5V

Velocity (Kelajuan)

Data dijana dan diproses dalam masa sebenar (real-time).

Konteks Perpustakaan: Rekod keluar-masuk pintu automatik, tempahan bilik, dan muat turun e-book secara langsung.
03 / 5V

Variety (Kepelbagaian)

Data hadir dalam pelbagai bentuk (berstruktur, tidak berstruktur, separa berstruktur).

Konteks Perpustakaan: Jadual keahlian, fail PDF tesis, rakaman video program, dan log emel rujukan.
04 / 5V

Veracity (Ketepatan)

Kualiti data yang tepat, bersih, dan bebas ralat supaya keputusan tidak tersasar.

Konteks Perpustakaan: Memastikan rekod buku, status ahli, dan statistik rujukan tidak bertindih atau rosak.
05 / 5V

Value (Nilai)

Keupayaan menukar data mentah menjadi maklumat berguna untuk tindakan.

Konteks Perpustakaan: Data pinjaman digunakan untuk cadangan pembelian buku baharu dan penambahbaikan OPAC.
1.5

Perbezaan Antara Data Tradisional dan Data Raya

Ciri Data Tradisional Data Raya (Big Data)
Isipadu (Volume) Kecil ke sederhana (MB/GB) Sangat besar (TB, PB, EB)
Jenis Data Berstruktur sahaja, cth: pangkalan data Berstruktur, tidak berstruktur & separa struktur
Kelajuan (Velocity) Dikemaskini secara berkala / batch Masa nyata / real-time
Sumber Data Terhad, cth: borang, sistem dalaman Pelbagai: media sosial, sensor, log web, IoT dll.
Analisis Analisis asas/deskriptif Analitik lanjutan: ramalan, pembelajaran mesin
Tujuan Operasi harian / laporan biasa Keputusan strategik / automasi / inovasi
Infrastruktur Pelayan biasa / relational DBMS Platform besar: Hadoop, Spark, Cloud, Data Lake
Kos Pemprosesan Lebih rendah, infrastruktur kecil Lebih tinggi, tetapi lebih nilai/keuntungan
1.6

Contoh Data Raya dalam Kehidupan Seharian

01

Media Sosial

Mengumpul data minat, likes, komen dan tontonan video untuk mencadangkan kandungan yang sesuai dengan minat pengguna.

02

Aplikasi Navigasi

Menggunakan data lokasi daripada jutaan pengguna untuk memberi laluan terbaik, maklumat trafik dan masa perjalanan yang tepat.

03

E-Dagang

Mengumpul data pembelian, carian produk dan sejarah pelanggan untuk cadangan produk dan promosi bersesuaian.

04

Penstriman

Data tontonan atau lagu yang dimainkan dianalisis untuk mencadangkan filem atau lagu yang mungkin disukai pengguna.

05

Perbankan Dalam Talian

Menggunakan data transaksi untuk mengesan aktiviti mencurigakan dan meningkatkan keselamatan akaun.

1.7

Analisis Data Raya & Kepentingan Pelbagai Sektor

Definisi Analisis Data Raya

Proses menganalisis data dalam jumlah yang sangat besar, kompleks, dan pelbagai (Big Data) untuk mendapatkan corak, trend, dan maklumat berharga daripada pelbagai sumber seperti media sosial, transaksi perniagaan, sensor, atau peranti pintar.

JENIS 04

02
2.1

Analisis Data Raya dalam Sektor Perpustakaan

TERAS 01

Pemahaman Tingkah Laku Pengguna

Menganalisis rekod pinjaman, carian OPAC dan waktu kunjungan untuk tahu minat serta keperluan pengguna.

TERAS 02

Pemilihan dan Pembangunan Koleksi

Menggunakan data pinjaman dan permintaan bahan supaya pembelian buku lebih tepat dan mengelakkan pembaziran bajet.

TERAS 03

Pengurusan Ruang dan Kemudahan

Memantau penggunaan ruang bacaan, komputer dan bilik diskusi untuk mengurus kapasiti dengan lebih baik.

TERAS 04

Perancangan Program dan Aktiviti

Merujuk data penyertaan dan maklum balas bagi memilih topik dan masa program yang paling diminati.

TERAS 05

Peningkatan Perkhidmatan Digital

Menyemak log akses e-book dan jurnal dalam talian untuk mengenal pasti platform popular dan waktu capaian tertinggi.

TERAS 06

Penanda Aras dan Pelaporan Prestasi

Menggunakan data analitik untuk penyediaan laporan KPI serta perbandingan prestasi antara cawangan.

3.1

7 Strategi Pembudayaan BDA (“Apa yang kita perlu buat?”)

01

Kesedaran dan Pendidikan Data

Beri pendedahan dan latihan asas kepada staf tentang kepentingan data dalam kerja harian.

02

Perubahan Pemikiran

Pupuk budaya membuat keputusan berdasarkan fakta dan data, bukan sekadar andaian.

03

Pembinaan Infrastruktur & Sistem Sokongan

Sediakan sistem pengumpulan dan penyimpanan data yang teratur serta mudah digunakan.

04

Polisi & SOP Berkaitan Data

Wujudkan garis panduan jelas tentang pengurusan, keselamatan dan perkongsian data.

05

Integrasi Dalam Kerja Harian

Jadikan semakan dan analisis data sebagai rutin dalam setiap unit perpustakaan.

06

Kolaborasi

Galakkan kerjasama dan perkongsian maklumat antara unit serta komuniti data perpustakaan.

07

Mulakan Kecil, Ukur, Kembangkan

Mulakan dengan projek rintis berskala kecil, nilai keberkesanannya, dan kembangkan secara berperingkat.
